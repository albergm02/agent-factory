# Agent Factory

A reusable, human-supervised AI software engineering system powered by Claude Code.

## Objectives

- Coordinate specialized AI agents.
- Use reusable Skills and project-specific instructions.
- Plan and execute software engineering tasks.
- Review code through independent evaluation.
- Run automated tests and quality checks.
- Require human approval for important decisions.
- Maintain traceability through GitHub Issues, Pull Requests and Releases.

## Principles

1. Human oversight over autonomous execution.
2. Small, verifiable changes.
3. Independent quality evaluation.
4. Explicit permissions and security boundaries.
5. Reusable architecture, independent of any particular project.
